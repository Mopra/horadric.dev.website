Your agents are waiting.
Now you can see it.

You run five Claude Code sessions. Four are working. One has been waiting on you for twelve minutes. You had no idea.

Horadric puts every session on your desktop as a tile, grouped by project. The one that needs you lights up. Click it and it's a real terminal.

No chat UI in the way. The terminal is the UI.
